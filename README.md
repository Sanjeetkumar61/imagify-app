# Imagify

Imagify is a full-stack AI-powered image generation web application that allows users to generate images from text prompts. It includes user authentication, credit-based usage, and a modern responsive interface. The application is built using the MERN stack and integrates an external AI image generation API.

---

## 🚀 Live Links

- **Frontend:** https://imagify-app-sandy.vercel.app
- **Backend API:** https://imagify-app-backend-kwqx.onrender.com

## ✨ Features

- User authentication (Signup / Login)
- Secure JWT-based authentication
- AI-powered image generation from text prompts
- Credit-based image generation system
- User-specific credit tracking
- Protected routes
- Clean and responsive UI
- RESTful backend API
- Error handling and validations
- Cloud-ready deployment


## 🛠️ Tech Stack

### Frontend
- React.js

### Backend
- Node.js
